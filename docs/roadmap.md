# 分阶段计划

当前进度：后端首版已完成并通过测试，见 apps/api/GOAL.md；以下阶段同时含尚未完成的前端交互，不据此推断后端未实现。

本文件保留产品阶段参考，不作为前后端串行开工要求。两端独立目标与进度分别见 [前端 GOAL](../apps/web/GOAL.md)、[后端 GOAL](../apps/api/GOAL.md)，通过 [API 契约](../packages/contracts/README.md) 联调。以下未勾选项目均待后续实现。

## 0. 工程底座（本次）

- [x] 前后端分离，独立构建，根目录统一命令。
- [x] React + TypeScript + Tailwind 自绘 UI、路由与模块入口。
- [x] Vapor 入口/应用分层、版本化健康接口与路由测试。
- [x] 前端开发代理、环境变量模板、共享 OpenAPI 目录。
- [x] 设备 / 剪贴板 / 文件 / 临时链接模块边界与架构草案。

## 1. 极简首页与主题

- [ ] 低饱和中性色、克制强调色与简洁手绘线条，聊天内容保持清楚易读。

- [ ] 简洁手绘风格、桌面/手机适配，重点完成 iOS 聚焦、键盘、安全区和滚动实机验收。
- [ ] 页面与状态平滑过渡，支持减少动态效果偏好。

- [ ] `/` 改为独立进入页，大图标 + `WebDrop` 字样，无冗余介绍。
- [ ] 品牌下方放四位数字房间号输入框，右侧依次为随机、加号图标按钮。
- [ ] 保留前导零，支持粘贴、数字键盘与未来扩位；随机按钮创建随机码房间，加号按输入号码创建。
- [ ] 加号作为创建房间入口；亮暗主题可切换，所有组件使用统一主题 token。

## 2. DropRoom 与递增难度 PoW

- [ ] 确定无账号首版的设备身份和会话模型。
- [ ] 四位房间号兼配对码，安全随机分配且活跃期间唯一；位数可配置。
- [ ] 新建房间默认允许持有效房间号者加入，创建者自动拥有管理权。
- [ ] 明确成员凭证、管理操作、房间有效期与号码回收策略；可选确认模式不改变默认开放规则。
- [ ] Swift 原生 PoW 挑战签发、验证、防重放和多维度限流。
- [ ] 尝试次数越多难度越高，支持冷却回落、难度上限和抗计数重置。
- [ ] React 自绘 PoW 状态组件，Web Worker 求解，适配亮暗主题。
- [ ] 协议测试向量、跨语言校验、移动设备基准与绕过/重放测试。
- [ ] 在线状态与断开处理，确定通知协议。

## 3. 文本剪贴板闭环

- [ ] 房间内聊天式文本消息，逐条发送、接收、主动粘贴与复制；新成员可见尚未过期的历史。
- [ ] 权限提示、手动复制兜底、文本大小与保留期限。

## 4. 文件与媒体传输

- [ ] 元数据持久化、存储适配器、上传会话与流式写入。
- [ ] 文件大小/配额/类型规则、进度、取消和失败回收。
- [ ] 接收下载、图片预览与视频播放；先完成基本传输，再评估断点续传。

## 5. 易记临时链接

- [ ] 确认短码格式、公开访问模式和默认有效期。
- [ ] 创建/复制分享页链接与媒体直链，支持过期与撤销。
- [ ] HEAD / Range、清理任务、缓存控制和解析限流。

## 6. 部署与增强

- [ ] HTTPS、反向代理、日志、运行配额与生产配置。
- [ ] 多设备真实网络验收；按需求评估 WebRTC 直传、PWA、断点续传。
