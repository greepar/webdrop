# API 错误与客户端恢复

对应 OpenAPI 0.4.0。逐接口状态码与允许的 code 以 OpenAPI responses 为准；下表汇总相同分支。message 仅用于展示，不作为程序分支。requestId 与响应头 X-Request-ID 用于定位问题。

| code | 客户端处理 |
| --- | --- |
| INVALID_INPUT / INVALID_JSON / INVALID_CODE / JSON_REQUIRED / HTTP_413 | 修正字段、编码、Content-Type 或请求体大小；不原样自动重试 |
| SESSION_REQUIRED | 建立或恢复会话，重新获取成员关系；新匿名会话不能恢复原 owner 权限 |
| CSRF_INVALID | GET session 读取当前 token，再重试；仍失败时停止 |
| ORIGIN_FORBIDDEN / FORBIDDEN / OWNER_REQUIRED | 停止操作，检查部署 origin 或当前权限 |
| IDEMPOTENCY_REQUIRED | 提供8–128位可见 ASCII 键 |
| IDEMPOTENCY_CONFLICT | 同键对应不同参数；确认是新操作后使用新键，不能盲目重试 |
| POW_INVALID | 重新申请挑战并求解；成功幂等重试保留原键及参数 |
| ROOM_PASSWORD_INVALID | 输入或更正房间密码，用新幂等键重新申请 PoW；缺失和错误密码统一返回403，不复用已消费的挑战 |
| CODE_TAKEN | 修改号码或随机创建；重新申请与新目标绑定的挑战 |
| ROOM_UNAVAILABLE | 房间不存在、锁定或当前会话被踢；统一提示无法加入，不推断具体原因 |
| ROOM_FULL / ROOM_CAPACITY / CODE_CAPACITY | 提示容量不足；429 等待 Retry-After 后再尝试，PoW 失效需重取 |
| OWNER_MUST_CLOSE | owner 先关闭房间，不能直接离开 |
| NOT_FOUND | 刷新资源/成员关系；不继续使用旧权限或缓存 |
| CURSOR_INVALID | 丢弃列表游标重新加载；SSE 无效数字游标返回400 |
| ITEM_LIMIT / TEXT_QUOTA / QUOTA_EXCEEDED / LINK_LIMIT | 删除不再需要的内容或链接，或等待释放配额后再尝试 |
| SIZE_MISMATCH / FILE_TOO_LARGE | 修正声明大小、文件或字节体；先查询上传状态再决定完整重传 |
| UPLOAD_STATE / UPLOAD_CANCELLED / UPLOAD_INCOMPLETE / UPLOAD_READY | 查询上传状态：uploaded 可 complete，ready 使用 itemId，failed 可完整重传；pending 才能开始上传，uploading 等待；cancelled/expired 创建新上传，ready 通过删除内容移除 |
| SHARE_EXPIRED / ASSET_EXPIRED | 提示资源不可用，停止自动下载；410墓碑清理后可能为404 |
| RATE_LIMITED / CAPACITY / UPLOAD_BUSY / STREAM_LIMIT | 429 按 Retry-After 秒数退避，避免并发重试；503 CAPACITY 不保证该响应头，采用有限退避 |
| STORAGE_ERROR / INTERNAL_ERROR / HTTP_* | 有限退避并记录 requestId；写入结果不确定时先查状态，有幂等键的操作保留原键和参数 |

未列出的框架错误由 default Error 信封承接，code 可为 HTTP_<status>。启动期 STORAGE_LOCKED / STORAGE_VERSION 不属于可调用 API 的错误。416 Range 为无响应体特例，依据 Content-Range 修正范围。HEAD 的错误也不带响应体，依据状态码处理。

SSE 建连前使用下列 HTTP 错误；200之后会话过期或成员撤权直接结束流，重连重新鉴权。内部 MEMBERSHIP_REVOKED 不作为 SSE data 事件发送。游标太旧或超前则发送 resync.required 并结束，客户端重新获取快照。
