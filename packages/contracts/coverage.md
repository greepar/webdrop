# 后端接口审查与覆盖

本次审查：2026-11-01，OpenAPI 0.5.0。当前契约包含36个 HTTP 操作（30个路径），已通过注册路由双向比对；HEAD 由 Vapor 的 GET 路由提供。注册覆盖不等于所有故障路径都已穷举，以下列出实际验证范围。

| 模块 | 接口覆盖 | 验证重点 |
| --- | --- | --- |
| 基础与会话 | 健康检查、能力配置、建立/恢复/读取会话 | Cookie、Origin、CSRF、错误信封、过期 |
| PoW | 挑战与创建/加入时校验 | 编码向量、难度升级/冷却、跨目标绑定、重复消费、来源限流 |
| 房间 | 创建、加入、读取、锁定、更换号码、关闭 | 号码冲突、owner 权限、并发人数、重复设备加入、空闲关闭 |
| 成员 | 列表、自己离开、房主踢人 | 权限撤销、owner 离开限制、SSE 访问失效 |
| 内容 | 列表、创建文字、删除 | 历史可见性、本人/owner 权限、幂等、事件顺序 |
| 文件 | 创建上传、状态查询、写入、完成、取消、GET/HEAD | 字节数、SHA256、失败重传、内存/磁盘、Range、下载授权 |
| 分享 | 创建、列表、撤销、公开元数据及原始内容 | 访问权限、有效期、关房撤销 |
| 实时事件 | SSE 订阅与重连 | 游标重放、resync、关闭事件、订阅释放 |

## 可选房间密码（0.4.0）

- 创建/加入支持可选 password，owner PATCH 可设置、替换或取消；Room 返回 hasPassword。
- 密码校验在 PoW 后执行，错误统一403 ROOM_PASSWORD_INVALID；锁定优先，已有成员保留访问。
- bcrypt 加盐存储，幂等记录也使用独立加盐哈希；快照恢复兼容旧字段，事件不泄漏密码。
- 本轮验证：Swift 23项、离线契约5项、前端类型/静态检查、前后端构建通过；真实 HTTP smoke 开启 schema 校验，通过200 KB内存与2 MB磁盘两条路径，包含房间密码流程。

## 契约精度修正（0.3.1）

- displayName 明确为80个 UTF-8 字节，恢复会话也校验输入；明确可省略/null的字段语义。
- 挑战申请与提交统一使用8–128位可见 ASCII 幂等键，capabilities 的 heartbeatSeconds 修正为实际的2秒。
- 各接口枚举错误状态与 code，[errors.md](errors.md) 提供恢复策略；框架异常保留 default。
- Event 按 type 严格关联 payload；upload.updated 为 Asset，heartbeat/resync.required 为 EventCursor。
- 独立契约验证器执行 x-maxUtf8Bytes 和 format 校验；smoke 增加 JSON 请求及 SSE 校验。
- 本轮验证：Swift 20项、离线契约4项、前端类型/静态检查及完整构建通过。当时沙箱禁止网络 socket；真实 HTTP smoke 已在0.4.0本轮补跑通过。

## 既有实现补全

- 增加 `GET /api/v1/uploads/{uploadId}`，上传者和房主可查询上传状态与完成后的 itemId；用于处理 PUT/complete 响应丢失。
- 修复会话过期被回收后，SSE 断开时订阅计数无法释放的问题。
- 小文件默认不超过1 MiB优先内存；总内存池64 MiB，分配包含并发上传预留，池满或大文件直接落盘。
- 内存文件删除、到期、取消和关房时释放；重启后删除丢失的附件消息、撤销其链接、清除相应成功缓存，同时保留文字及其它幂等记录。
- 两种存储使用同一套授权、HEAD、Range 和分享接口；内存字节不序列化到磁盘快照。

## 自动验证

- `swift test --package-path apps/api -j 4`：后端业务、并发、生命周期、持久化、混合存储、PoW 及契约路由检查。
- `scripts/api-smoke.py`：真实 HTTP 的会话→PoW→入房→文字→上传→下载→分享→SSE→踢人→关闭流程。
- `--file-bytes 200000` 覆盖内存路径；`--file-bytes 2000000` 覆盖磁盘路径（默认阈值下）。
- 安装 jsonschema 后追加 `--validate-contract`，验证实际 JSON 响应满足 OpenAPI schema。

## 当前有意保留的边界

- 无账号首版，不提供密码登录、设备永久封禁或 owner 凭证恢复。
- 上传失败可整文件重传，未实现分片断点续传；100 MB 上限保持不变。
- 元数据使用单进程快照，尚未实现多实例数据库、对象存储和跨节点消息同步。
- 媒体只做有限签名识别与浏览器预览，不提供转码或病毒扫描。
- PoW 手机耗时校准和生产并发压测仍需后续进行；不把路由覆盖或测试通过描述为已穷尽所有安全场景。
