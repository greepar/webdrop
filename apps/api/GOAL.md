# WebDrop 后端目标

范围：`apps/api`。技术栈：Swift + Vapor。专注业务规则、状态、权限、存储和稳定 API，独立维护本文件的进度。首版业务目标已实现并通过独立后端测试及真实 HTTP 验证。前端目标独立跟踪。

唯一跨端协作入口是 [API 契约](../../packages/contracts/README.md)。不依赖 React 组件、页面结构、主题或前端状态管理。通过 HTTP、文件流、事件契约和测试客户端独立实现及验收。

## DropRoom 与身份

- [x] 新建 Channel 对应一个 DropRoom，默认允许任何持有效房间号的用户加入，无需创建者逐个批准。
- [x] 创建者自动拥有管理权。管理权由服务端成员身份与权限决定，不由房间号或前端标记决定。
- [x] 初始房间号为四位数字，同时作为配对码；允许前导零，例如 `0042`。
- [x] 房间号在活跃房间中唯一；随机创建使用安全随机分配，指定号码创建由服务端原子校验占用；内部房间 ID 与对外房间号分离。
- [x] 房间号作为字符串存储和传输，输入组件、验证规则与接口支持以后增加位数。
- [x] 后续请求使用成员会话凭证；知道房间号不代表拥有管理权。

- [x] 服务端支持随机分配号码创建和指定号码创建，原子处理冲突；与 UI 按钮布局无关。
- [x] 创建者可锁定加入、踢人、更换号码和关闭房间，管理操作均校验成员关系及角色。
- [x] 成员凭证撤销同时影响后续 API 与实时订阅，不仅断开单条连接。

## 已确认的业务规则

- [x] 新成员能读取房间内全部尚未过期的历史内容。
- [x] 普通成员可删除自己的内容、分享自己的文件；owner 可管理房间全部内容及链接。
- [x] 创建者暂时离线不关闭房间；无人在线持续 30 分钟后关闭，在线判定容忍后台短暂断线。
- [x] 每房间最多 10 台设备，后续可配置；原子校验人数，重连去重。
- [x] 单文件上限 100,000,000 字节（100 MB），验证实际上传字节和资源配额。
- [x] 分享链接默认有效期 24 小时；手动或自动关闭房间时同时撤销关联公开链接。

## Swift 原生 PoW

- [x] 原生 Swift 实现挑战签发、难度策略、验证与防重放，使用成熟密码学原语，不依赖额外验证服务。
- [x] 随尝试次数增加提高难度，冷却后回落，设置上限；计数与难度由服务端维护。
- [x] 结合会话、来源与全局信号限流，刷新、换房间号或重复申请挑战不能轻易重置来源级成本。
- [x] 挑战短时有效，绑定会话、操作和请求参数；一次性消费与操作授权原子化，拒绝跨房间、跨操作和并发重放。
- [x] 挑战签发和验证接口自身限流；服务端低成本校验，不替客户端求解，不把证明当作成员身份或管理权限。
- [x] 输出明确的挑战、错误与冷却契约，提供跨语言测试向量。当前使用14–20 bits、10分钟计数窗口；协议和跨语言向量已验证，移动端耗时校准留待前端接入。

## 内容、资源与分享

- [x] 小文件使用有总预算的临时内存，大文件或池满时流式落盘；支持配置阈值、并发预留、重启失效处理和资源回收。
- [x] 提供上传状态查询，支持丢失响应后的恢复决策；契约端点与注册路由双向覆盖检查。

- [x] 提供文字条目创建、查询、分页与权限化删除，按契约提供稳定标识、发送者和时间。
- [x] 流式文件上传、取消、完成校验、资源状态及失败回收；未完成资源不可下载或分享。
- [x] 图片、视频与普通文件统一资源模型，支持受保护的原始内容下载、HEAD 和媒体 Range。
- [x] 分享短码独立于房间号，提供分享元数据与原始内容直链，执行有效期、撤销和资源引用清理。
- [x] 实时成员/内容/房间事件符合协议，支持授权撤销、重连、去重游标和过期后的重新同步。
- [x] 统一业务错误、幂等写请求、参数验证、会话防护与持久化；只向客户端返回契约允许的数据。

## 独立实施与验收

1. 会话、房间和成员权限。
2. PoW、限流及受保护的创建/加入操作。
3. 内容、文件资源、分享与过期清理。
4. 实时事件及完整 API 契约验证。

使用 Swift Testing / VaporTesting 及 HTTP 测试客户端验收，无需等待 UI。覆盖权限、并发、幂等、PoW 重放、上传限额、过期撤销和事件恢复。后端不负责页面视觉或浏览器交互测试；细节见 [开发规范](../../docs/development.md)。

已落实：owner 主动离房需先关闭房间，匿名凭证丢失不恢复所有权；内容保留至删除或关房；已识别 PNG/JPEG/GIF/WebP/MP4 可内联，其余类型作为附件。具体协议见 [protocol.md](../../packages/contracts/protocol.md)。
